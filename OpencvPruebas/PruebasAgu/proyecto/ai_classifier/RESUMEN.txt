🎯 CARACTERÍSTICAS PRINCIPALES:

  ✨ Multi-tarea: Clasifica tipo, rotación, meeple y posición simultáneamente
  ✨ Transfer Learning: Usa modelos preentrenados (ImageNet)
  ✨ Data Augmentation: Aumenta datos automáticamente
  ✨ Easy to Train: Interface simple y clara
  ✨ GUI de Anotación: Herramienta visual para etiquetar
  ✨ Análisis Completo: Métricas detalladas y visualizaciones
  ✨ Modular: Código organizado y reutilizable
  ✨ Bien Documentado: Guías paso a paso

📊 ARQUITECTURA DEL MODELO:

     Input Image (224×224×3)
            ↓
     ┌──────────────────┐
     │  EfficientNet-B0 │  ← Transfer Learning (ImageNet)
     │    (Backbone)    │
     └──────────────────┘
            ↓
     ┌──────────────────┐
     │  Shared FC Layer │  ← 512 neurons
     │   (Features)     │
     └──────────────────┘
            ↓
        ┌───┴───┬───────┬────────┐
        ↓       ↓       ↓        ↓
     ┌────┐ ┌────┐ ┌────┐  ┌──────┐
     │Type│ │Rot.│ │Mee.│  │ Pos. │
     │Head│ │Head│ │Head│  │ Head │
     └────┘ └────┘ └────┘  └──────┘
        ↓       ↓       ↓        ↓
       25      4       2        9
     classes classes classes classes


💻 EJEMPLO DE USO RÁPIDO:

  # 1. Anotar datos
  python annotate.py tiles/ --output annotations.json

  # 2. Entrenar
  python train.py --train data/train.json --val data/val.json --epochs 50

  # 3. Evaluar
  python evaluate.py models/best_model.pth data/test.json

  # 4. Predecir
  python inference.py models/best_model.pth batch tiles/ --output results.json

🎮 INTEGRACIÓN CON EL DETECTOR:

  from inference import classify_tiles_from_detector

  # Clasifica todas las losetas extraídas
  results = classify_tiles_from_detector(
      detector_tiles_dir='tiles/',
      model_path='models/best_model.pth',
      output_json='board_results.json'
  )

  # Procesar resultados
  for tile in results:
      print(f"{tile['tile_letter']} - {tile['rotation']*90}°")
